What the agent will and won't do

Clear from day one: the agent is powerful, but some jobs are deliberately off-limits.

The agent will do all of this

  • Read, search and combine the files you allow
  • Build reports and export them to Excel / PDF
  • Remind you about service, insurance and registration renewals
  • Retry a failed step on its own, and tell you what happened

The agent will never do this

  • Log in to any website or app, or enter an OTP / 2FA code
  • Make a payment or do any banking task
  • Delete a file or send anything to anyone without asking you first
  • Live GPS tracking — that needs a GPS device in the vehicle or the provider's API

How it works

01

Install & allow access

The agent installs on the laptop. You choose only the folders it may read — the rest of the laptop stays closed to it.

02

Send a voice note — from anywhere

Send a WhatsApp-style voice note or a typed command from your phone, wherever you are. The agent on the laptop picks it up and gets to work.

03

The agent does the work

Every step shows on screen: which file it opened, how many rows it read, what the result was. Nothing is hidden.

04

Report in your hand

The report on screen, and the Excel file too — sent back to your phone. If it needs forwarding, the agent confirms with you first.
